# Telegram 账号代购销售系统

## 📖 简介

自动化 Telegram 账号代购销售系统，支持商品同步、自动代购、余额管理、订单追踪。

## ⚙️ 配置说明

编辑 `.env` 文件：

```env
# Telegram API 配置
API_ID=2040
API_HASH=b18441a1ff607e10a989891a5462e627

# 销售机器人配置
BOT_TOKEN=你的机器人Token
BOT_USERNAME=你的机器人用户名
ADMIN_IDS=管理员用户ID

# 源机器人配置
SOURCE_BOT=hao24bot
BUYER_SESSION=sessions/new/573166025225
BUYER_2FA=600

# 定价配置
MARKUP_FIXED=0.05       # 固定加价（美元）
MIN_PROFIT=0.05         # 最低利润（美元）

# 同步配置
SYNC_INTERVAL=3600      # 同步间隔（秒）
REQUEST_DELAY=3         # 请求延迟（秒）
```

## 📖 使用说明

### **启动系统**

```bash
cd C:\Users\Administrator\.openclaw\workspace\shopbot
python main.py
```

### **首次运行**

1. 系统会自动初始化数据库
2. 登录代购账号
3. 抓取商品列表
4. 启动销售机器人

### **用户使用流程**

1. 用户发送 `/start` 给销售机器人
2. 点击 "📱 Telegram账号"
3. 选择分类
4. 选择商品
5. 确认购买（自动扣除余额）
6. 系统自动代购并发送文件

---

## 🔧 核心功能

### **1. 商品同步**
- 每1小时自动抓取
- 支持翻页（最多3页）
- 自动去重
- 检测循环

### **2. 自动代购**
- 返回按钮导航
- 精确匹配商品
- 支持翻页查找
- 接收3个文件并压缩

### **3. 余额管理**
- 充值（手动）
- 购买扣款
- 失败退款
- 余额变动记录

### **4. 订单追踪**
- 订单状态追踪
- 文件存储
- 历史订单查询

---

## 💰 定价策略

**固定加价模式：**
- 源价格 + 固定加价
- 例如：$0.33 + $0.05 = $0.38

**最低利润保护：**
- 确保每笔订单至少有 $0.05 利润

## 📊 数据库表结构

### **users（用户表）**
- user_id: 用户ID
- balance: 余额
- created_at: 创建时间

### **products（商品表）**
- id: 商品ID
- category: 分类
- name: 商品名称
- original_price: 原价
- selling_price: 售价
- stock: 库存

### **orders（订单表）**
- id: 订单ID
- user_id: 用户ID
- product_id: 商品ID
- status: 状态
- files_path: 文件路径

## ⚠️ 注意事项

1. **Session 文件安全**
   - 不要泄露 session 文件
   - 定期更换代购账号

2. **限流保护**
   - 使用返回按钮导航
   - 避免频繁 `/start`

3. **余额管理**
   - 充值功能需要管理员手动操作
   - 购买失败会自动退款

4. **文件存储**
   - 订单文件保存在 `orders/` 目录
   - 定期清理旧文件

## 🐛 故障排查

### **问题1：代购失败**
- 检查 session 文件是否有效
- 检查源机器人是否正常
- 检查商品是否还有库存

### **问题2：机器人无响应**
- 检查 BOT_TOKEN 是否正确
- 检查网络连接
- 查看日志输出

### **问题3：数据库锁定**
- 停止所有进程
- 删除数据库文件
- 重新启动系统
